# Departments Microservice

A microservice for managing departments, built with FastAPI and PostgreSQL. This service is part of a larger employee onboarding/offboarding system.

## Architecture

- **Framework**: FastAPI (Python 3.11)
- **Database**: PostgreSQL 15
- **API Documentation**: Swagger UI (OpenAPI)
- **Container**: Docker

## Features

- Create new departments
- Retrieve department by ID
- List all departments
- Persistent storage with PostgreSQL
- Swagger documentation
- Docker containerization

## Quick Start

### Prerequisites

- Docker and Docker Compose
- Python 3.11+ (for local development)
- Beekeeper Studio (optional, for DB management)
